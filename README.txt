YEMEKHANE YOKLAMA - GÜNCELLEME

Bu sürüm iki ayrı CSV aktarımı sunar:
- Öğrenci listesini aktar: yemekhane_ogrenciler.csv
- Yoklama kayıtlarını aktar: yemekhane_yoklamalar.csv
- Diğer telefondan CSV al: seçilen dosya türünü başlıklardan tanır; mevcut verileri korur ve aynı öğrenci (ad+şube) / aynı yoklama (tarih+ad+şube) tekrarını atlar.

ÖNEMLİ:
1) Eski uygulama verileri aynı tarayıcı/ana ekran uygulaması depolamasında kalır; bu güncelleme aynı yerelStorage anahtarlarını kullanır.
2) Güncelleme öncesi her iki telefonda da mevcut yoklamaları CSV dışa aktararak yedekleyin.
3) Bu klasördeki üç dosyayı GitHub Pages deposunun kök dizinine yükleyip değişiklikleri kaydedin. Sonra iki iPhone'da uygulamayı internet varken açıp yenileyin. iOS eski önbelleği tutarsa Safari'de sayfayı yeniden açın.
4) Gerçek öğrenci verilerini GitHub deposuna koymayın. Yalnızca uygulama dosyalarını yayınlayın.
5) CSV aktarımı elle yapılır; çevrimdışı iki telefon arasında otomatik eşitleme yoktur.
